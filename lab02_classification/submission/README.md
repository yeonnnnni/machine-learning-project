# Lab 02 — Classification & Regression with scikit-learn

## Environment

- Python 3.10.x
- CPU only

Install the required packages:

```bash
pip install -r requirements.txt
```

## Reproduce results

Run the completed implementation from the project root:

```bash
python src/lab02.py
```

This command generates `results.json`.

## Run public tests

```bash
python -m pytest tests/ -q
```

The implementation uses seed 42 as specified in the provided skeleton.
